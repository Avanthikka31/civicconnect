# CivicConnect – Citizen Public Services Portal

A student-built frontend prototype using HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `civicconnect_frontend` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Try the service detail buttons, scheme search and application tracker.

Demo reference number: `CC2026001`

## Deploy with GitHub Pages
1. Create a public GitHub repository named `civicconnect`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and test the public URL in a private/incognito browser window.

## Important
This is a frontend-only educational prototype. It uses sample data, has no backend or real citizen records, and is not an official government website. Do not enter personal or sensitive information.
